# E-Hentai Scroll Reader v2.0.14

## English

An unofficial continuous reader with two modes: **Load 10 pages at a time** (default) and **Load all pages**. Includes English/Chinese controls, adjustable width, light/dark backgrounds, one automatic refreshed-URL retry, and position restoration when applying settings.

Download the attached **ehentai-scroll-reader-v2.0.14.zip**, extract it, open `chrome://extensions`, enable Developer mode, then choose Load unpacked and select the folder containing manifest.json. Keep only one reader version enabled.

Page-by-page loading was removed. Old saved page-by-page preferences fall back to 10-page mode. All-pages loading is unchanged from v2.0.9; this is not the experimental capped-download build.

Validation used synthetic pages in local Chrome. Live-site compatibility and a manual end-to-end installation have not been verified for this release package. Large books can still use substantial memory.

## 简体中文

仅保留 **每次加载 10 页（默认）** 与 **全部加载** 两种模式。支持中英文、宽度调整、黑白背景、失败后重新获取地址并自动重试一次，以及应用设置后恢复阅读位置。

下载附件 **ehentai-scroll-reader-v2.0.14.zip** 并解压，打开 `chrome://extensions`，开启开发者模式，选择“加载已解压的扩展程序”，选中包含 manifest.json 的文件夹。只开启一个版本。

已移除逐页加载；旧设置会自动回退到每次加载 10 页。全部加载沿用 v2.0.9，未加入实验版的并发限制。

已通过本地 Chrome 模拟页面测试。本发布包尚未进行真实网站实测及人工完整安装验证；大本漫画仍可能占用较多内存。
