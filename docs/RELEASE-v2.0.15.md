# E-Hentai Scroll Reader v2.0.15

## English
- Cleaner toolbar layout for split-screen and narrow windows.
- New width − / + buttons: adjust by 10 px and save automatically.
- Both loading modes remain unchanged.

Download ehentai-scroll-reader-v2.0.15.zip and extract it. Replace the files in your installed extension folder, reload the extension on chrome://extensions, then refresh the reading page. New users: enable Developer mode and choose Load unpacked for the folder containing manifest.json.

Verified with local synthetic Chrome pages: English/Chinese layouts at widths 390–1920 px, width buttons, limits, saving, and position restoration after settings. Live-site testing has not been performed for this release.

## 简体中文
- 优化分屏和窄窗口工具栏排版，按钮整齐分行。
- 新增宽度 − / ＋，每次调整 10 px，自动保存。
- 两种加载模式保持不变。

下载并解压 ehentai-scroll-reader-v2.0.15.zip，将文件覆盖到原扩展安装文件夹，在 chrome://extensions 重新加载扩展，再刷新漫画页。首次安装请开启开发者模式，点击“加载已解压的扩展程序”，选择含 manifest.json 的文件夹。

已通过本地 Chrome 模拟测试：390–1920 px 中英文布局、加减宽度、边界、保存与设置后的阅读位置恢复。本版尚未进行真实网站实测。
